操作步骤

步骤一：基础检查

  • 检查本地网络是否正常（能否打开其他网站）。
  • 重启路由器或切换网络（如从WiFi切到移动数据）。

步骤二：清除DNS缓存

  • Windows：打开命令提示符，输入 ipconfig /flushdns。
  • macOS：终端输入 sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder。

步骤三：更换DNS

  • 将DNS改为公共DNS：114.114.114.114 或 8.8.8.8。
  • 操作路径：网络设置 → 更改适配器选项 → 属性 → IPv4 → 使用自定义DNS。

步骤四：清除浏览器缓存

  • Chrome：设置 → 隐私与安全 → 清除浏览数据 → 选择“所有时间” → 清除。
  • 其他浏览器类似。

步骤五：尝试备用入口
